На этой неделе я завершил первый этап индивидуального проекта — 
развёртывание личного сайта с помощью Hugo и GitHub Pages.

## Что было сделано

Сначала я установил генератор статических сайтов Hugo (расширенную 
версию с поддержкой Sass/SCSS) через `.deb`-пакет в WSL Ubuntu. Затем 
создал новый проект командой `hugo new site` и подключил тему оформления 
как Git-подмодуль, что позволяет отдельно отслеживать версию темы.

После этого я разместил проект в удалённом репозитории на GitHub, 
настроив аутентификацию через SSH-ключ вместо пароля, который GitHub 
больше не поддерживает для операций с Git.

Отдельным шагом стала настройка параметра `baseURL` в конфигурационном 
файле — он должен точно совпадать с адресом, по которому GitHub Pages 
будет отдавать сайт, иначе стили и ссылки работают некорректно.

Наконец, я настроил автоматическое развёртывание с помощью GitHub 
Actions: при каждом push в ветку `main` сайт автоматически собирается 
и публикуется.

## Трудности и их решение

В процессе работы возникло несколько ошибок — от проблем с DNS в WSL, 
из-за которых Git не мог подключиться к GitHub, до конфликтов между 
содержимым разных тем, вызывавших ошибки сборки Hugo. Каждая ошибка 
помогла лучше понять, как устроены Git, Hugo и процесс автоматического 
развёртывания.

## Итог

Сайт был успешно опубликован и доступен по адресу 
`https://ushie47.github.io/blog/`. Это заложило основу для второго 
этапа проекта — наполнения сайта личной информацией и содержимым.
