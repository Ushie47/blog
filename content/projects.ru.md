## Личный сайт

Статически генерируемый персональный сайт, созданный с помощью Hugo и 
автоматически развёртываемый на GitHub Pages через GitHub Actions.

- **Стек технологий:** Hugo (extended), тема Congo, Git, GitHub Actions
- **Возможности:** страница профиля, блог, раздел достижений, ссылки 
  на научные/исследовательские платформы
- **Репозиторий:** github.com/Ushie47/blog
- **Сайт:** ushie47.github.io/blog
